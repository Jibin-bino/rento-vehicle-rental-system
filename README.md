
# Rento — Vehicle Rental Management System

A full-stack vehicle rental web application built using Python Flask.

## Features
- User registration and login
- Vehicle search and details
- Date-based availability checking
- Booking and price calculation
- Payment processing
- User dashboard
- Admin dashboard

## Technologies
- Python and Flask
- SQLAlchemy
- HTML, CSS, Bootstrap, JavaScript
- SQLite / PostgreSQL

## Installation
1. Clone the repository.
2. Create and activate a virtual environment.
3. Install dependencies using `pip install -r requirements.txt`.
4. Configure environment variables.
5. Initialize the database as documented.
6. Run the application.
